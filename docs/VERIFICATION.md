# 0.1.0 离线验收记录

记录日期：2026-10-15。执行平台：Mac / Python 3.12，使用已安装的锁定依赖。所有响应来自合成 fixture、内存 ASGI 网关或临时数据库；没有访问生产网关，没有导入 WindPy，没有发送真实 Wind 数据请求。

## 结果

- 不安装 core 的独立客户端/网关测试：发现 109 项，103 项通过，6 项外部 core 专项按设计跳过，零失败或错误。
- 明确指定外部 core 后：109 项全部通过。core 专项使用模拟 SDK 返回或 mock runner，验证共享锁、预算、缓存和计量，不是实际 WindPy 数据验收。
- stdio 客户端子进程实际初始化并发现 30 个工具，在阻止导入 WindPy / wind_bridge 的条件下成功。
- 配置生成覆盖本机绝对路径、空格、中文、私有配置引用及 Unix venv 符号链接保留；这些检查不替代 Windows 客户端实机验收。
- 调度覆盖多客户端轮转、同客户端顺序、多个数据库连接原子领取及限流、重启保持、不确定任务暂停。
- 计量覆盖角色隔离、重复回传不重复累计、旧任务与待回传任务未知、native/mock 分开、缓存及历史回执不重复计量。
- 滚动窗口覆盖默认 7×24 小时、午夜不重置、逐次观测时间、七天边界、延迟回传、缺字段及巨大时间戳不会阻断结果回传、当前额度失败与历史错误区分。
- 时间格式化支持跨 Unix epoch 的滚动窗口，避免 Windows 对负时间戳的系统限制；迁移测试显式关闭旧数据库连接，避免 Windows 文件占用。
- 入队拒绝与丢失响应区分：确定未接收的 429 不提示轮询不存在任务；提交响应丢失保留原 job_id，避免重复取数。
- 发布器仅打包显式允许的源码/文档/模板，拒绝源文件及输出目录符号链接，并测试 core、SDK、凭据、运行数据和旧包排除。

## 三平台远端检查

[GitHub Actions 记录](https://github.com/spikewzy/wind-terminal-relay/actions/runs/38662918485) 对应代码提交 `d2d7a9d`，Python 3.12，三个平台均成功完成依赖安装、依赖一致性检查、离线测试及源码包构建。

| 平台 | 发现 | 通过 | 明确跳过 |
|---|---:|---:|---:|
| macOS | 109 | 103 | 6 |
| Linux | 109 | 103 | 6 |
| Windows | 109 | 98 | 11 |

6 项为未配置外部 core 的专项检查；Windows 另外跳过 5 项需要特权创建符号链接的检查。这些是实际远端离线检查，不是 Windows 客户端连接生产执行端的真实数据验收。各平台单独构建 ZIP，最终发布附件使用另行核对的整包 SHA256，不以不同机器生成的 ZIP 必须同哈希为验收条件。
