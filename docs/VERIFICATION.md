## 结果

- 不安装 core 的独立客户端/网关测试：发现 90 项，84 项通过，6 项外部 core 专项按设计跳过，零失败或错误。
- 明确指定外部 core 后：90 项全部通过。core 专项使用模拟 SDK 返回或 mock runner，验证共享锁、预算、缓存和计量，不是实际 WindPy 数据验收。
- stdio 客户端子进程实际初始化并发现 30 个工具，在阻止导入 WindPy / wind_bridge 的条件下成功。
- 配置生成覆盖本机绝对路径、空格、中文、私有配置引用及 Unix venv 符号链接保留；这些检查不替代 Windows 客户端实机验收。
- 调度覆盖多客户端轮转、同客户端顺序、多个数据库连接原子领取及限流、重启保持、不确定任务暂停。
- 计量覆盖角色隔离、重复回传不重复累计、旧任务与待回传任务未知、native/mock 分开、缓存及历史回执不重复计量。
- 入队拒绝与丢失响应区分：确定未接收的 429 不提示轮询不存在任务；提交响应丢失保留原 job_id，避免重复取数。
- 发布器仅打包显式允许的源码/文档/模板，拒绝源文件及输出目录符号链接，并测试 core、SDK、凭据、运行数据和旧包排除。
